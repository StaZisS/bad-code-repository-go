# Courier Management System (Go + Gin)

Инструкции по подготовке окружения и запуску серверного приложения на Go и Gin Gonic.

## Предварительные требования
- **Go 1.25+** — установите последнюю версию Go и убедитесь, что `go version` выводит 1.25.x или выше.
- **Git / Make (необязательно)** — репозиторий содержит все необходимые зависимости в `go.mod`, дополнительные инструменты не требуются.
- **cURL / HTTP‑клиент** — для проверки REST‑эндпоинтов можно использовать `curl`, `httpie`, Postman и т.п.

## Быстрый запуск
1. Установите Go 1.25 и выполните:
   ```bash
   go version
   ```
   чтобы проверить корректность установки.
2. В корне проекта скачайте зависимости:
   ```bash
   go mod tidy
   ```
   (команда уже выполнена в репозитории, но при необходимости её можно повторить).
3. Запустите HTTP‑сервер:
   ```bash
   go run ./cmd/server
   ```
   По умолчанию сервис стартует на `http://localhost:8080` и использует встроенное in-memory хранилище. При старте автоматически создаётся админ `admin / admin123`, а также можно создавать менеджеров и курьеров через REST API.

### Переменные окружения
| Переменная         | Назначение                                          | Значение по умолчанию |
|--------------------|-----------------------------------------------------|------------------------|
| `PORT`             | Порт HTTP‑сервера                                   | `8080`                 |
| `JWT_SECRET`       | Секрет для подписи JWT токенов                      | `dev-secret`           |

Пример запуска с кастомными параметрами:
```bash
PORT=9090 JWT_SECRET="super-secret" go run ./cmd/server
```

## Запуск тестов
Полный комплект тестов (юниты/интеграция для контроллеров и бизнес-логики):
```bash
go test ./...
```
Тестовый стенд (`internal/testutil`) поднимает Gin Router в памяти, поэтому никаких внешних сервисов или баз данных поднимать не нужно.

## Полезные команды
| Действие                          | Команда                                     |
|----------------------------------|---------------------------------------------|
| Запуск сервера                   | `go run ./cmd/server`                       |
| Сборка бинаря                    | `go build ./cmd/server`                     |
| Полный прогон тестов             | `go test ./...`                             |
| Запуск конкретного теста         | `go test ./internal/api -run TestAuthController` |

## Структура проекта
- `cmd/server` — точка входа приложения.
- `internal/api` — HTTP‑роуты, middleware, DTO для запросов.
- `internal/service` — бизнес-логика, расчёты маршрутов, проверки весов/времени.
- `internal/storage` — in-memory репозиторий.
- `internal/testutil` — вспомогательный тестовый набор для интеграционных сценариев.
- `go.mod`, `go.sum` — описание зависимостей.

## Шаги для ручной проверки
1. Получить токен администратора:
   ```bash
   curl -X POST http://localhost:8080/auth/login \
        -H "Content-Type: application/json" \
        -d '{"login":"admin","password":"admin123"}'
   ```
2. Создать менеджера или курьера (заголовок `Authorization` обязателен).
3. Через `POST /deliveries` или `POST /deliveries/generate` протестировать бизнес-правила.
